# Global & Workspace Rules for AI Agents

## Project Memory File Requirement
- **Memory File Mandate**: Every project MUST contain a `MEMORY.md` file in its root directory.
- **Single Source of Truth**: The `MEMORY.md` file acts as the primary repository context, documenting project identity, tech stack, architecture, sitemap/routes, design tokens, and deployment procedures.
- **Maintenance**: Whenever major updates, architectural changes, or new features are introduced, `MEMORY.md` MUST be updated immediately.
- **Agent Workflow**: Before starting non-trivial tasks in any project, inspect `MEMORY.md` to understand context and existing constraints.
